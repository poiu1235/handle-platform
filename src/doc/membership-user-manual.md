# 会员页 · 完整功能操作手册

> 适用版本：PRD v3.2（2026-09-03）。覆盖管理端「会员」标签的全部功能：
> 列表三级交互、静默系统、进站提醒、日历展示模式、单条新增/编辑、批量导入。
> 规则依据见 `lifestyle-cardpack-prd-v3.md`（交互）与 `cards-db.md`（数据契约）；
> 边界编号（B1–B39、4-Bxx）指 PRD 第四章。

---

## 1. 页面入口与数据加载

- 登录后进入管理端首页，顶部标签为 **余额 / 会员 / 优惠券**。「会员」即生活卡包（原"卡包"，2026-09-03 更名，内部路由与键名不变）。
- **数据时机**：登录态就绪后自动请求一次卡数据（`GET /api/cards`，内部完成**结算 + 全量拉取**）；此后会话内不再自动重拉——所有增删改走就地更新（单请求、列表即时刷新、不重拉列表）。同会话内**跨天**（回焦或可见态轮询检测到）视为新进站：提醒标志重置并重新结算拉取。
- 顶部状态行显示登录邮箱；接口异常显示红色错误条。
- 底部 **⊕ FAB**（仅会员标签内）：两项菜单——「批量增加」（跳批量导入页）、「增加一条」（弹窗）。

## 2. 列表模式（默认）

### 2.1 工具行

- **排序**（与模式切换同一行，右端是「列表 ⇄ 日历」分段控件）：
  - 「按到期日」（默认，最先到期在前——自动续费卡的到期日 ≡ 扣款日，一个键覆盖两种关注）；
  - 「按名称」（拼音序）；「按更新时间」（默认最新在前，再点反向）。
- **「展示已过期的卡片（N）」开关**：默认关——过期卡从列表收起，不占空间；打开后过期卡回归队尾沉底（灰色）。次数用完（非过期）的卡**不受此开关影响**，常驻列表。关闭开关时若正展开的卡恰好过期，自动收回展开态。

### 2.2 卡片三级展开

| 层级 | 进入方式 | 展示内容 |
|------|---------|---------|
| **折叠** | 默认 | 卡名 + 旗标（自动续费 $ 图标；静默图标仅静默态显示）+ 双槽信息：左「剩 N 次」（次数卡）/ 右「剩 N 天」主信息；扣款窗口内右槽变「N 天后扣款」；过期「已过期」、用完「已用完」 |
| **半展开** | 点击折叠卡 | 宽卡：卡名 + 旗标 + 日期区间（2026.08.31 − 2026.11.29）+ 续费摘要（每月续 · 09-14 扣款）；露出「展开修改」按钮；左右滑手势激活 |
| **全量详情** | 点「展开修改」 | 全字段区块（见第 4 节）；点头部回落半展开（不直接收回折叠） |

- 点击列表空白处 → 所有展开收回折叠。
- **沉底规则**：已过期 = 失效灰沉底；次数用完（未开续费）= 弱化灰蓝沉底；**续费中的卡次数用完不沉底**（下个周期会重置）。沉底卡右槽必有文字原因，不只靠颜色。

### 2.3 滑动手势（仅半展开态）

- **右滑**（仅次数类生效卡——有次数且未用完）：
  - 浅拉松手 → 露出「**清零**」按钮，点击 = 剩余次数归 0（标记用完）；
  - **拉到底或快甩** = **次数减一**（滑动中底部提示「拉到底 · 清空次数」渐显，减一后自动回缩可连续滑）；
  - 减到 0 / 清零触发按卡型提示（见 8.3）。
- **左滑** → 露出「**删除**」→ 红色确认弹窗。**续费中的卡有强化警告**：「删除只清除本地记录，不会帮你取消对应平台的续费——请先自行前往对应 App 取消，否则后续扣款将不再有任何提醒。」删除不可逆。

### 2.4 名称行旗标

- **$（dollar.svg）**：自动续费中，随续费开关实时出现/消失，纯展示。
- **静默图标**：**仅静默状态显示**（提醒中不显示）。两种形态：mute.svg = 本周期静默、all-mute.svg = 永久静默。**点击循环档位**：本周期 →（续费卡）永久 → 解除；非续费卡点击直接解除。循环每档都有 notice 反馈（「已恢复提醒」「已静默至本周期结束，顺延后自动恢复提醒」「已永久静默，需手动恢复」）。

## 3. 全量详情（「展开修改」）

头部自上而下：

1. **meta 行**：有效期 `2026.08.31 − 2026.11.29 · 剩 22 天`；续费不完整时顶部出现黄色警告条（缺扣款日/周期 → 不结算不提醒）。
2. **次数区块**（自带开关）：
   - 开启时：**「剩余」数值编辑**（改动后出现 保存/取消，保存才落库）；每周期次数**不在此区块**——它在续费区块的「周期刷新次数」（见下）。
   - 开关拨关 = 关闭次数能力：剩余/每周期字段一并清空（数据库约束联动），卡退回纯期限卡；可逆、无确认。
   - 事后补开：拨开 → 填剩余次数（必填 > 0）→ 保存。
3. **续费区块**（自带开关，**开关是续费唯一入口**）：
   - **拨开** = 进入草稿态（不立即生效）：周期下拉（每周/每月/每季/每年/固定天数）→ 选「固定天数」再填天数 → 扣款日输入框渐进出现（**限本周期内**：周=今天+7、月=+1 月、季=+3 月、年=+1 年、固定=今天+N−1）→ **保存**才提交（含 DDL 同步 = 扣款日）；「取消」回退真值。
   - **周期刷新次数**（次数能力开启时出现；与新增弹窗同款）：「无限 / 固定次数」下拉 +「每周期刷新」输入框。
     - 给从未配置的卡开续费 → **默认固定次数 = 库内剩余次数**；
     - 选「无限」→ 清空数值 + 提示：*「无限：次数不会随周期重置，将保持当前数值（适合由外部扫描校准的次卡）；若希望每周期恢复次数，请选固定次数」*。
   - **拨关** = 立即关闭续费（notice：关闭后将不再自动顺延…）；**total_sessions 一并置空**，剩余次数保留。
   - **已过期卡开关置灰**（B23）：先改终止日期恢复生效才能开启。
4. **静默菜单**：「静默」按钮点开三项（自动续费卡：不静默/本周期静默/静默；非续费卡：不静默/静默），点外部自动收起。
5. **「编辑」**：改**卡名**（重名 → 报错「已有同名卡券」）/ 起始日 / 终止日期。**续费卡的终止日期置灰**（B21）——顺延由结算自动完成；确要手动改先关闭续费。

## 4. 进站提醒弹窗（alert）

- **触发**：进站结算后，存在命中窗口且未被排除的提醒 → 弹出；一次会话只弹一次，跨天重置。z 层全站最高。
- **条目**：色点（记录色）+ 卡名 + 标签（「剩 N 天」/「MM-DD 扣款」/「已用完」叠加；静默后显示「本周期静默/永久静默」标注）。
- **右侧静默图标按钮（2026-09-03 新交互）**：
  - 图标 = 当前状态：🔔 notification.svg 提醒中 / mute.svg 本周期静默 / all-mute.svg 永久静默；
  - **点击循环下一档**（自动续费卡：提醒→周期→永久→提醒；非续费卡：提醒⇄永久）；
  - **点击不关闭弹窗、条目不重排不消失**——顺序在弹窗打开时冻结，可反复切换、可点回来；确认结果看条目上的文字标注；
  - 点击条目本体 → 关闭弹窗并半展开该卡；「知道了」= 关闭忽略。
- 排除规则：过期卡不提醒；静默卡不提醒；次数用完只排除**到期**提醒——**扣款提醒照常**（钱的事不看次数）。

## 5. 日历展示模式（2026-09-03 新增）

- **进入**：排序行右端「列表 ⇄ 日历」切换。
- **工具栏**：`‹ 2026年9月 ›` 翻月 +「今天」一键回当月（已在当月则置灰）+「卡片筛选 N/M」+ 模式切换。
- **月视图**：周一为首列；今天 = 品牌蓝日期胶囊 + 整列淡底。
- **日程条**：每张卡一条 起始日 → 终止日 的跨天色条（颜色与列表同一张卡一致）；跨周折行、跨月断口显示 ‹ ›；**卡名只显示在本月第一次出现的头部段**，后续周只画色条。
- **置灰**：**今天之前的日段整段灰**（同一条上以今天为界双色，今天当天算彩色）；过期卡的历史段即灰色删除线——翻到过去月份自然可见，不受列表过期开关影响。
- **卡片筛选**：多选下拉，**最多同时 5 张**。卡数 ≤5 默认全选；>5 默认不选（日历空态引导勾选）。勾满 5 张后未选项置灰禁勾，底部提示上限；支持**卡名关键词搜索**；「全选」在总数 >5 时禁用；筛选在两种模式间保留。
- **点日程条** → 弹出**只读详情**（状态/有效期含剩余或已过期天数/次数/自动续费/静默五行）——**日历内不可修改**；改卡回到列表模式操作。卡被删除后弹窗自动消失。

## 6. 增加一条（弹窗）

一种卡 + 两个可选能力，无互斥卡型。

- **卡名**：全称直接录入（如 Tony-理发季卡）；**与已有卡同名 → 自动预填该卡当前状态**，提交即覆盖它（静默设置保留不动）；改名离开既有键 → 回到空白默认。
- **起始日期**：默认今天，可改历史（≥ 今天−2 年）。
- **终止日期**：不填 = 最长 2 年（创建时物化为今天+2 年）；开续费时置灰并显示「= 下次扣款日」（有效期跟随扣款日）。
- **次数能力开关**：开 → 填**剩余次数**（必填 > 0）。
- **自动续费开关**（过期卡置灰，B23）：拨开进入草稿态 → 选周期（周/月/季/年/固定天数）→ 扣款日渐进出现（限本周期内）→ 保存生效。
  - **周期刷新次数**（次数能力开着时出现）：默认「**固定次数 = 剩余次数**」；可切「无限」（清空数值 + 无限说明提示，见 8.4）。
- 提交成功走 notice（落入提醒窗口会附加提示），不弹 alert。

## 7. 批量增加（批量导入页）

- **粘贴格式**：首行可以是表头（可识别中文别名），无表头按默认 9 列列序；Tab / 逗号 / 空格分隔均可：

  ```
  卡名,起始日,终止日期,剩余次数,每周期次数,自动续费,扣款周期,合同天数,扣款日
  ```

  列位速记：期限卡 3 格、次卡 5 格、周期续费卡 `名字,起始,终止,,,是,月,,扣款日`（续费行**扣款日列可省略**——见下方规则）、次数+续费卡 `名字,起始,终止,剩余,总次,是,月,,扣款日`。
- **核心规则（2026-09-03）**：**续费行的扣款日一律强制 = 卡片终止日期（DDL）**——行内写的扣款日被忽略，预览 diff 会显示旧 → 新；没写终止日期的续费行，扣款日 = 物化默认（今天 + 2 年）。**扣款周期与合同天数二选一**，同填报错。
- **解析规则**：日期接受 `2026-9-3 / 2026.9.3 / 2026/9/3`；自动续费接受 是/否/true/false/1/0/y/n/开/关；周期接受 周/月/季/年 或 week/month/quarter/year；空行忽略；错误行逐条报错（**统一按行号升序**），有错误时提交按钮禁用。
- **预览三组**：新增（带「默认」标注）/ 更新（旧 → 新全量对照——唯一人工关卡）/ 错误。同名卡批内逐字段取最后值。行级过期三分支：行过期+库内正常 → 更新为过期；+库内已过期 → 跳过；+库内没有 → 新增过期记录（黄色标注）。
- **提交**：成功 notice 汇报「新增 N / 更新 N / 跳过 N」；提交后再粘同一份 → 全部转「更新 · 无字段变化」（upsert 幂等）。导入不触发提醒，下次进站统一计算。
- 备用数据：`doc/cards-import-paste-normal-30.md`（30 条合法样例）与 `cards-import-paste-demo.md`（错误场景样例）可直接粘贴验证。

## 8. 规则速查与常见问题

### 8.1 提醒窗口

- 到期提醒：`[DDL−15 天, DDL]`（含两端）；扣款提醒（仅续费卡）：`[扣款日−7 天, 扣款日]`。窗口内每次进站都提醒，嫌吵用静默。

### 8.2 静默三态速查

| 图标 | 状态 | 点击后 |
|------|------|--------|
| notification.svg（铃铛） | 提醒中（仅提醒弹窗内显示） | → 本周期静默（续费卡）/ → 永久静默（非续费卡） |
| mute.svg | 本周期静默 | → 永久静默（续费卡）/ → 解除（非续费卡） |
| all-mute.svg | 永久静默 | → 恢复提醒 |

- 本周期静默在**顺延/结算推进日期时自动解除**；永久静默只手动解除。静默只关提醒，状态照常、循环照跑。

### 8.3 次数用完了怎么办（按卡型）

- **续费 + 固定刷新次数**：不用管——下个扣款日结算自动重置为每周期次数。
- **续费 + 刷新无限**：不会自动重置（有内联提示）。出路：① 详情页直接改剩余；② 批量导入粘贴外部真实次数校准；③ 把周期刷新改成固定次数，下个扣款日起自动恢复。
- **非续费次卡**：改回数字即恢复（沉底自动取消）；或等扫描覆盖。

### 8.4 删除须知

- 删除不可逆；续费中的卡删除**不会取消平台扣款**——先去对应 App 取消订阅，再删本地记录。

### 8.5 字段校验速查

| 字段 | 规则 |
|------|------|
| 卡名 | 必填；与其他卡重名不可（编辑时） |
| 起始日 | [今天−2 年, 今天] |
| 终止日期 | ≥ 起始日 且 ≤ 今天+2 年；不填创建 = 今天+2 年 |
| 剩余次数 | ≥ 0（导入）/ > 0（手动创建与补开） |
| 每周期次数 | > 0（固定刷新模式） |
| 扣款周期 / 合同天数 | 二选一；合同天数 ≥ 1 |
| 扣款日（手动） | [今天, 本周期上限]；**（批量导入）强制 = 终止日期** |
