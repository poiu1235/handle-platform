## 1. 这是什么产品

**所有付费项目，一眼看清；该处理的，进站即见。**

「会员」标签管理你名下的各类生活会员卡 / 订阅（健身、洗车、理发、按摩、瑜伽、美甲、影音会员等）。它只回答四个问题：

- 这张卡**还剩多少天**？
- **还剩多少次**？
- **下次什么时候扣款**？
- 扣款之后新的到期日（DDL）是什么？

它**不记金额、不算花销、不做核销打卡**；数据可以由你的外部自动化工具扫描后批量粘贴导入，也可以手动逐条维护。

**一张卡只有一个名字**（建议按「商户名-卡名」全称录入，如「Tony-理发季卡」「腾讯视频-月度VIP」），同名即同一条记录。每张卡是"一个期限卡基座 + 两个可选能力"：

| 能力 | 开启后的行为 | 关闭后的行为 |
| --- | --- | --- |
| **次数** | 记录剩余次数（可选配每周期刷新配额） | 次数字段整体移除，退回纯期限卡 |
| **自动续费** | 扣款日到达后自动顺延一个周期（默认续费） | 到期后自然过期，到期提醒照常 |

两个能力互相独立，都可以创建时开启，也可以事后在详情页随时补开/关闭。

## 2. 进入页面与数据加载

1. 浏览器打开 `/app`，登录后进入**管理端首页**。顶部为深蓝色头部（英文眉题 Membership Overview + Handle 字标 + 登录状态胶囊），下方是三个标签：**余额 / 会员 / 优惠券**。
2. 点「**会员**」标签即进入会员卡清单。计数徽标实时显示卡的总数。
3. **数据加载**：登录态就绪后系统自动执行一次「进站加载」——一次请求同时完成**结算**（自动续费卡的周期追赶，见第 13 节）和**全量拉取**，随后清单立刻呈现。
   - 加载中显示「**正在加载会员卡…**」；
   - 失败显示红色条「**加载会员卡失败：{原因}**」；
   - 已有数据时再次结算失败不阻塞浏览，列表顶部出现轻提示「**部分数据可能未及时刷新，请稍后重新打开**」（数秒后自动消失）。
4. **"进站"的定义**：刷新页面 / 新开标签页 / 外部链接进入，或同一次会话内**跨天**后重新回到窗口（含每 30 分钟的可见态检测发现跨天）。每次进站都会重新结算一次。**站内切换标签、跳转导入页再返回不算进站**，不会重复弹提醒。
5. 右下角 **⊕ 悬浮按钮（FAB）** 是本标签的新增入口（仅会员标签显示）：
   - 「**批量增加**」→ 跳转批量导入页（第 12 节）；
   - 「**增加一条**」→ 打开单条新增弹窗（第 7 节）。

## 3. 列表模式：工具行

会员标签激活时的工具区自上而下：

### 3.1 排序按钮（幽灵胶囊，可横向滚动）

| 按钮 | 默认方向 | 说明 |
| --- | --- | --- |
| **按到期日**（默认选中） | ↑ 升序 | 最先到期的在最前。自动续费卡的到期日恒等于扣款日，所以这一个键同时照顾"到期"与"扣款"两种关注 |
| **按名称** | ↑ 升序 | 按拼音排序 |
| **按更新时间** | ↓ 降序 | 最近改动的在前；再点一次反向 |

- 再点已选中的按钮 = 翻转方向（按钮文字尾部显示 ↑/↓）。
- **沉底卡永远排在最后**，不参与上述排序（见 4.4）。

### 3.2 展示模式分段控件（工具行右端）

「**列表 | 日历**」两个按钮。默认列表；切到日历后整个列表区变为月视图日历（第 11 节）。切换是纯前端行为，不重新请求。

### 3.3 过期卡筛选开关

「**展示已过期的卡片（N）**」iOS 式开关，**默认关**：

- 关：过期卡整体收起，不占列表空间；若全部卡都过期，列表内显示引导「**当前列表只显示未过期的卡——打开上方「展示已过期的卡片」开关展开过期卡。**」
- 开：过期卡回归队尾沉底（失效灰）。
- 关闭开关的瞬间，如果正展开的卡恰好是过期卡，会自动收回展开态。
- **次数用完（但未过期）的卡不受此开关影响**，常驻列表。

## 4. 卡片的三种形态（三级展开）

清单采用三级交互骨架：**折叠 →（点击）半展开 →（点环角徽标）全量详情**。折叠与半展开是同一张卡片的展开动画（"从小变大"），全量详情是独立页面层。

### 4.1 折叠态（默认）

```
┌──────────────────────────────────────────────┐
│ ◆ 卡名全称  [$] [🔇]        剩 8 次   ◔ 22 天 │
└──────────────────────────────────────────────┘
```

- **左侧**：小菱形（无图标卡）或 App 图标 + 卡名全称（15px，超长省略）。
- **卡名右侧旗标**：
  - **$（money.svg）**：自动续费中。随续费开关实时出现/消失，纯展示不可点。
  - **静默图标**：**仅静默状态才显示**（提醒中不显示）。remind-disable.svg = 本周期静默、close-remind.svg = 永久静默。**点击循环档位**：本周期 →（续费卡）永久 → 解除；非续费卡点击直接解除。每档都有轻提示反馈（见 14.2）。
- **右侧双槽**：
  - 左槽：**次数胶囊**——「剩 N 次」；已用完时变灰色胶囊「**已用完**」。
  - 右槽：**30px 天数环**（圆环内数字 + 旁缀"天"字）。
    - 常态数字 = 剩余天数；
    - 扣款窗口内（扣款日 −7 天起）数字 = 扣款倒计时；
    - **环色**：常态绿 → 到期窗口内橙 → 扣款窗口内红；已过期 / 已用完 = 灰。
- **卡底颜色**：正常卡 = 图标主色→白的渐变（无图标卡 = 记录色，同一张卡永远同色，清单与日历一致）；已过期 = 失效灰；已用完 = 弱化灰蓝（见 4.4）。

### 4.2 半展开态（点击折叠卡）

```
┌──────────────────────────────────────────────────┐
│ ◆ 卡名全称 [$] [🔇]              ◔ 22 天  [↘]    │
│   2026.08.31 − 2026.11.29                        │
│   [续费中] 每月 · 09-14 扣款        剩 8 次       │
└──────────────────────────────────────────────────┘
```

- **标题自适应放大**（20–30px，图标 20–40px），长卡名自动缩小不让位。
- 新增两行信息：
  - **日期区间**：`2026.08.31 − 2026.11.29`（起始日 − 终止日）；
  - **续费摘要**：续费卡显示蓝色小标签「续费中」+ 周期（`每月`/`每 30 天`）+ `· 09-14 扣款`；未开续费显示「未开自动续费」。
- **右侧 65px 大天数环**：环内标签「天剩余 / 天后扣款」；环右下角贴一个 28px 的 **↘ 徽标按钮（展开修改）**——这是进入全量详情的唯一入口。
- 环下方纵排：次数胶囊（剩 N 次 / 已用完）与标签（如「09-14 扣款」）。
- 点击半展开卡本体 = 收回折叠。
- 点击列表空白处 = 收回所有展开。

### 4.3 全量详情（点「展开修改」徽标）

见第 6 节。详情头部点击或点「收起」按钮 → 回落半展开（不直接收回折叠）。

### 4.4 沉底规则（两种灰，原因可辨）

| 状态 | 底色 | 文字/圆环 | 是否可恢复 |
| --- | --- | --- | --- |
| **已过期** | 失效灰 `#CDD3D9` | 压灰；环照常（灰态显示 0 天） | 改终止日期到未来即恢复（"重新激活"） |
| **已用完**（剩余 0 次且未开自动续费） | 弱化灰蓝 `#D9E2EC` | 压灰 + 灰色「已用完」胶囊；命中扣款窗口时追加「MM-DD 扣款」标签 | 改回次数 / 导入覆盖即恢复；**续费中的卡次数用完不沉底**（下个周期会自动重置） |

沉底卡若同时命中扣款窗口，扣款提醒照常（钱的事不看次数）。

## 5. 滑动手势（仅半展开态）

> 仅鼠标/触摸拖动卡体有效；卡上的按钮（展开修改、静默）不会触发拖动。

### 5.1 右滑 = 次数操作（仅"次数类生效卡"：带次数且未用完）

```
      ┌──────────────────────────┬────────┐
右滑 →│  （卡体，随拖动渐隐）      │  ➖ 减一 │  浅拉松手停在这里
      └──────────────────────────┴────────┘
      ┌──────────────────────────────────────┐
      │  ▓▓▓▓▓▓▓▓▓▓ 拉到底 · 清空次数 ▓▓▓▓▓▓ │ → 整卡飞出 = 清零提交
      └──────────────────────────────────────┘
```

- **浅拉**（不到行宽一半）松手：左侧露出「**减一**」按钮（深蓝底），点击核销一次，面板自动回缩，可连续操作。
- **拉过行宽一半**或**快速右甩**：卡面出现蒙层进度「**拉到底 · 清空次数**」（越过半程点亮蓝色填充），整卡向右飞出 220ms 后**直接提交清零**——没有二次确认（操作可逆），行随后以"已用完"灰态重新归位。
- 清零 / 减到 0 的提示按卡型区分：
  - **自动续费卡**：「**次数已清零 · 卡将沉底不再提醒；若订阅仍在续，下个周期会自动恢复次数——想让卡停止续费，请关闭自动续费（续费区块开关）**」；
  - **非续费卡**：无特殊提示（行为自明）。

### 5.2 左滑 = 删除

- 左拉 40px 以上（或快速左甩）松手：右侧吸附「**删除**」按钮（红底）。
- 点击「删除」→ 弹出红色确认弹窗（第 9 节），**删除是唯一不可逆的操作**。

## 6. 全量详情页逐项操作

从半展开态点环角「展开修改」徽标进入。头部为 22px 图标 + 18px 卡名 + 右上角「⤒ 收起」按钮。

### 6.0 meta 行与警告

- **meta 行**：`有效期 2025.09.20 − 2026.09.19 · 剩 22 天`（已过期则显示「已过期」）。
- **续费信息不完整警告**（黄色）：「**续费信息不完整：缺少扣款日或周期，不会结算也不会提醒——请在下方续费区块补全。**」——仅在历史数据缺字段时出现。

### 6.1 次数区块（自带开关）

```
┌ 次数   剩 8 / 共 30 次            [开关 ●] ┐
│  剩余 [ 8 ]                    （改动后出现）│
│                                [保存] [取消] │
└─────────────────────────────────────────────┘
```

- **头部**：「次数」+ 副文字 `剩 N / 共 M 次`（未开启显示「未开启次数」）+ 开关。
- **改剩余次数**：直接点数值输入框修改 → 出现「保存 / 取消」→ 保存才落库（草稿流，取消回退真值）。校验：「**剩余次数需为不小于 0 的整数**」。
- **事后补开次数**（开关从关到开）：出现「剩余」输入框，**必填且 > 0**（「**开启次数时剩余次数必填且需大于 0**」）→ 保存。
- **关闭次数能力**（开关从开到关）：剩余/每周期字段**一并清空**（数据库联动约束），卡退回纯期限卡。无确认（双向可逆）；若原为 0 沉底，关闭后卡恢复原位。
- 注意：**每周期次数不在这里配**——它已收编为续费区块的「周期刷新次数」（6.2）。

### 6.2 续费区块（自带开关；**开关是续费的唯一入口**）

**开启自动续费（草稿流，保存才生效）：**

1. 拨开开关 → 进入草稿态，**周期先清空**（副文字提示「先选周期再选扣款日；保存后开启，有效期将与扣款日一致」）。
2. 选「**周期**」下拉：`每周 / 每月 / 每季 / 每年 / 固定天数`。选「固定天数」需再填天数（正整数，如 30）。
3. 周期选齐后「**扣款日**」日期输入框**才出现**（渐进披露），可选范围**限本周期内**：
   每周 = 今天+7 天；每月 = 今天+1 个月；每季 = +3 个月；每年 = +1 年；固定 N 天 = 今天+N−1 天。超出范围报「**扣款日需在今天至 {上限} 之间（本周期内）**」。
4. **周期刷新次数**（次数能力开启时出现）：下拉「**无限 / 固定次数**」+ 数值框。
   - 给从未配置过的卡开启续费 → **默认「固定次数」= 当前剩余次数**（开续费的直觉就是"每周期恢复到买的时候"）；
   - 选「无限」→ 清空数值并提示：「**无限：次数不会随周期重置，将保持当前数值（适合由外部扫描校准的次卡）；若希望每周期恢复次数，请选固定次数**」。
5. 点「**保存**」→ 提交（校验顺序：请先选择扣款周期 / 请选择扣款日 / 固定天数需为正整数 / 配额次数需为大于 0 的整数（或选「无限」））。成功 notice「**已开启自动续费**」。
   **保存后有效期（终止日期）自动变为扣款日**——续费卡的 DDL ≡ 扣款日，系统全站强制。
6. 点「**取消**」→ 回退到服务端真值。

**已开启卡的修改**：周期 / 天数 / 扣款日 / 刷新次数同款草稿流，改动后出现「保存 / 取消」；保存时改扣款日会同步写终止日期。

**关闭自动续费**：开关拨关**立即生效**（无草稿），notice「**关闭后将不再自动顺延，卡会在 DDL 后自然过期**」。注意两点：

- 终止日期**停留在最后一次的扣款日值**，之后自然过期；
- 「周期刷新次数（每周期次数）」**一并置空**，剩余次数保留；下次重开续费需重新配置。

**已过期卡的开关置灰**：「**卡已过期，请先顺延有效期恢复生效，才能开启自动续费**」——先在「修改」弹窗把终止日期改到未来。

### 6.3 静默菜单

底部操作区左侧「**静默**」按钮（当前状态带图标：提醒中铃铛 / 本周期静默 / 永久静默）：

- 点开菜单：续费卡三项「**不静默 / 本周期静默 / 静默**」，非续费卡两项「**不静默 / 静默**」；
- 点菜单外部自动收起；
- 选择后 notice：「**已解除静默**」/「**本周期内不再提醒，下次顺延后自动恢复**」/「**已静默，可在此解除**」。

### 6.4 修改入口

底部操作区「**修改**」按钮（带笔形图标）：

- **续费中的卡该按钮置灰**，点击提示「**自动续费卡不可修改：请先关闭自动续费（续费区块开关），再来编辑**」；
- 非续费卡点击 → 打开修改弹窗（第 8 节）。

### 6.5 名称行快捷静默

折叠 / 半展开态卡名右侧的静默图标（仅静默态显示）点击即循环下一档，效果与 alert 行内按钮一致（见 10.2），无需进详情。

## 7. 新增一张卡（弹窗）

入口：FAB →「增加一条」。弹窗标题「**添加一张卡**」，顶部提示：「**与已有卡「卡名」相同将直接覆盖那条记录的最新状态。**」

### 7.1 字段逐项

| 字段 | 规则 | 校验失败提示 |
| --- | --- | --- |
| **卡名** | 必填；建议「商户名-卡名」全称。与已有卡**同名** → 自动预填该卡全部当前状态（见 7.2） | 「请填写卡名」 |
| **图标**（可选） | 选择器：搜索框 + 默认精选 11 个常用图标 + 「无」。**不动它 = 按卡名自动匹配**（选择器显示「自动」标注）；手动选 = 落库指定；选「无」= 明确不要图标；已手动选择后可「恢复自动」 | — |
| **起始日期** | 默认今天，可改历史；范围 [今天−2 年, 今天] | 「起始日期需在 {下限} 至 {今天} 之间」 |
| **终止日期** | 未开续费：label「终止日期（不填 = 最长 2 年）」——留空则创建时物化为今天+2 年；填写需 ≥ 起始日 且 ≤ 今天+2 年。开续费：字段置灰，label 变「终止日期（= 扣款日）」，值跟随扣款日 | 「终止日期不能早于起始日期」/「终止日期不能晚于 {上限}」 |
| **次数开关** | 开 → 「剩余次数」必填且 > 0 | 「剩余次数必填且需大于 0」 |
| **自动续费开关** | 拨开进入草稿态：先选周期（每周/每月/每季/每年/固定天数）→ 固定天数填天数 → 扣款日输入框出现（限本周期内）→ 保存生效。**周期刷新次数**（次数开着时）：默认「固定次数 = 剩余次数输入值」 | 「请选择扣款周期」/「固定天数需为正整数」/「请选择扣款日」/「扣款日需在今天至 {上限} 之间（本周期内）」/「配额次数需为大于 0 的整数」 |

其他固定提示：续费区块内「**先选周期再选扣款日；扣款日限本周期内，保存后开启，有效期与扣款日一致。**」；终止日期已过的卡续费开关置灰（「**终止日期已过：请先填写有效的终止日期，才能开启自动续费**」）。

### 7.2 同名覆盖预填（重要机制）

输入的卡名与已有卡**完全相同**时：

1. 弹窗出现红色提示：「**已有同名卡「{卡名}」：已预填它的当前状态，提交将以表单内容覆盖该记录（静默设置保留不变）。**」
2. 表单自动预填该卡的起始日 / 终止日 / 次数 / 刷新次数 / 续费设置 / 图标——**"维持"不是"开启"**：续费中的卡不改开关，提交后仍是续费中。
3. 把名字改走（不再同名）→ 表单回退到空白默认值。
4. 提交按 **diff-only** 原则：只把相对既有记录**变化了的字段**发给服务端；静默设置永不携带（保留库内值）。

### 7.3 提交

- 底部「取消 / 保存」；提交中显示「保存中…」且双按钮禁用。
- 失败：弹窗内红色 notice 显示原因，表单内容保留。
- 成功：弹窗关闭，列表顶部绿色/蓝色 notice「**已添加「{卡名}」**」；若落入了到期提醒窗口，追加「**· 剩 N 天，已进入到期提醒窗口**」。操作反馈只走 notice，不会触发 alert。

### 10.2 条目与操作

弹窗是全站最高浮层；没有"确认续费"按钮——续费是默认行为，本弹窗只提供"不吵"（静默）与"处理"（进详情）两个方向。

## 12. 批量导入（批量增加页）

入口：FAB →「批量增加」，或空态提示中的链接。路由 `/app/cards-import`，标题「**会员卡批量导入**」。

### 12.1 操作流程

1. 阅读说明：「**把外部工具的扫描结果整表复制粘贴到下方（首行可以是列名，支持 Tab / 逗号 / 空格分隔）。同名卡逐字段取最后值；已有卡只更新行内携带的字段、缺失保留现值；新卡缺失字段取默认（终止日期 → 今天 + 2 年）。提交前请在「更新」预览里核对每一处 旧 → 新。**」
2. 把表格数据**整表复制粘贴**进大文本框。
3. 下方实时出现**解析预览**（三组，见 12.4），有错误行时提交按钮禁用。
4. 点「**提交（新增 X · 更新 Y）**」（提交中「提交中…」）。
5. 成功 notice：「**已提交：新增 X / 更新 Y / 跳过 Z。提醒将在下次进站时按新数据统一计算。**」文本框自动清空。**导入不触发结算、不弹提醒**。

### 12.2 粘贴格式

- 分隔符：Tab / 逗号 / 空格均可；首行可以是表头（识别中文别名，见下），否则按默认 9 列列序：

```
卡名,起始日,终止日期,剩余次数,每周期次数,自动续费,扣款周期,合同天数,扣款日
腾讯视频-月度VIP,2026-09-01,2026-09-30
爱奇艺-连续包月,2026-09-03,2026-10-03,,,是,月
山姆会员店-年度续费,2026-09-03,2027-09-03,,,是,年
```

- **列位速记**：期限卡 3 格；次卡 5 格（卡名,起,止,剩余,每周期）；周期续费卡 `名字,起始,终止,,,是,月`（**扣款日列可省略**——续费行扣款日强制 = 终止日期）；次数+续费卡再加两格。
- **表头别名**（大小写不敏感，命中 ≥2 个别名才按表头取列）：卡名/名称/卡片名/项目；起始日/起始日期/开始日期；终止日期/终止日/到期日/截止日期/有效期至/ddl；剩余次数/剩余/余次；每周期次数/总次数/共；自动续费/续费；扣款周期/周期；合同天数/天数；扣款日/下次扣款日/扣款日期。

### 12.3 单元格解析规则

| 字段 | 接受格式 | 错误提示 |
| --- | --- | --- |
| 三个日期列 | `2026-9-3` / `2026.9.3` / `2026/9/3` / `2026-09-03` | 「{起始日期/终止日期/扣款日}「{原文}」不是有效日期」 |
| 三个整数列 | 整数（剩余 ≥0，其余 >0） | 「{剩余次数/每周期次数/合同天数}「{原文}」不是整数」 |
| 自动续费 | 是/true/1/y/yes/开；否/false/0/n/no/关 | 「自动续费「{原文}」无法识别（用 是/否）」 |
| 扣款周期 | 周/月/季/年 或 week/month/quarter/year | 「扣款周期「{原文}」无法识别（周/月/季/年）」 |

行级业务校验（与预览同则）：「缺少卡名」「起始日期需在 {X} 至 {Y} 之间（配置 A）」「终止日期不能晚于 {X}（配置 B）」「终止日期早于起始日期」「**扣款周期与合同天数只能二选一**」「每周期次数需大于 0」「剩余次数不能为负数」「合同天数需为正整数」「开启自动续费需选择扣款周期或填写合同天数」「新增行只带每周期次数、缺剩余次数」「自动续费为开，但缺少扣款周期或合同天数（行内未携带且库内现值为空），请在行内补全」。

**核心规则（续费行）**：**扣款日一律强制 = 卡片终止日期（DDL）**——行内写的扣款日被忽略，预览 diff 如实显示 旧 → 新；没写终止日期的续费行，扣款日 = 物化默认（今天 + 2 年）。

**能力保护**：库内次数能力**未开启**的卡，更新行携带的次数字段**打包宽容忽略**（不自动重开能力，预览标注「次数字段已忽略（能力未开启）」）；续费关闭的卡携带扣款字段同样忽略（「扣款字段已忽略（未开续费）」）。

### 12.4 预览三组

1. **新增 N 条**：表格（卡名 | 有效期 | 次数 | 续费）。由默认值填充的字段标注「{字段名} 默认」；带次数标注「次数能力开启」；过期行标注「**新增过期记录**」。
2. **更新 N 条 · 跳过 N 条 · 请核对 旧 → 新**（默认展开，**唯一的人工核对关卡**）：每卡一张对照卡，动作标签「**覆盖更新** / **将更新为过期** / **跳过（库内已过期）**」；逐字段列 `字段名  旧值 → 新值`（无变化显示「与库内当前状态一致，无字段变化」，空值显示「（空）」）。**发现不对 → 直接改上方文本框原文 → 重新解析**。
3. **错误 N 行 · 修正后才能提交**：浅红块逐行「**第 X 行：{原因} —「{原文}」**」（解析错误与分类错误合并后按行号升序）。

**行级过期三分支**（行判定过期 = 行内 DDL < 今天）：行过期 + 库内正常 → 更新为过期（判死落库）；+ 库内已过期 → 跳过；+ 库内没有 → 新增过期记录。

其他状态提示：「正在加载会员卡快照…」「加载会员卡失败：{原因}」「当前库内没有卡：所有有效行都将作为新增写入。」

提交后再粘贴同一份内容 → 全部转为「更新 · 与库内当前状态一致」（upsert 幂等，无重复数据）。

> 样例数据：`src/doc/cards-import-paste-normal-20.md`（20 条合法样例）、
> `cards-import-paste-normal-30.md`（30 条）、`cards-import-paste-demo.md`（错误场景）可直接粘贴验证。

## 13. 数据是如何自动维护的（结算机制）

**你唯一需要理解的一条**：自动续费卡的周期推进由系统在**你进站的那一刻**自动完成，无需任何操作。

- **触发**：每次"进站"（刷新 / 新开 / 跨天回焦 / 可见态 30 分钟轮询发现跨天）。
- **算法**：对每张 开了自动续费 且 扣款日已过去的卡：`while 扣款日 < 今天：扣款日 += 1 个周期，终止日期 += 1 个周期`（两日期恒同值推进）；带次数且配置了「固定刷新次数」→ 剩余次数重置为每周期次数，未配置 → 次数保持等扫描校准。
- **周期算法**：合同固定天数类（`每 30 天`）精确推进 N 天；自然日历类（`每月`）按日历推进，月末自动钳制（1/31 → 2/28 → 3/28，锚点收缩是预期行为）。
- **幂等**：无论隔多久进站、几台设备同时进站，结果一致。
- **"本周期静默"自动解除**：任何导致终止日期实际变化的写入（结算顺延、手动顺延、导入推进）都会自动解除本周期静默；永久静默不受影响。
- **多端**：所有写入路径"后写覆盖先写"，无冲突提示；本地与远端的短暂不一致由下次进站自动收敛。
- **「今天」口径**：以你设备的本地时区为准（跨时区交替使用偏差 ≤1 天，可接受）。

## 14. 规则速查表

### 14.1 字段校验

### 14.2 静默三态

| --- | --- | --- | --- |
| remind.svg（铃铛） | 提醒中（仅 alert 弹窗内常驻显示） | → 本周期静默（续费卡）/ → 永久静默（非续费卡） | 「已静默至本周期结束，顺延后自动恢复提醒」/「已静默，不再提醒」 |
| remind-disable.svg | 本周期静默 | → 永久静默（续费卡）/ → 解除（非续费卡） | 「已永久静默，需手动恢复」/「已恢复提醒」 |
| close-remind.svg | 永久静默 | → 恢复提醒 | 「已恢复提醒」 |

详情静默菜单的文案：「已解除静默」「本周期内不再提醒，下次顺延后自动恢复」「已静默，可在此解除」。本周期静默在终止日期变化时自动解除；永久静默只手动解除。

### 14.3 天数环颜色

| 颜色 | 触发条件 |
| --- | --- |
| 🟢 绿 | 常态（不在任何提醒窗口） |
| 🟠 橙 | 进入到期窗口（距终止日 ≤15 天） |
| 🔴 红 | 进入扣款窗口（距扣款日 ≤7 天）——优先级高于橙 |
| ⚪ 灰 | 已过期 / 次数用完（环照常显示，弧与数字变灰） |

静默**不改变**环色（静默只是不弹提醒，显示照常）。

### 14.4 操作反馈语义

- **notice**（顶部/列表瞬时提示条，数秒自动消失）：一切主动操作的结果（新增、保存、静默、清零等）。
- **alert 弹窗**：只有进站被动发现的提醒，一次会话一次。
- **确认弹窗**：只有不可逆的删除。

## 15. 常见问题 FAQ

**Q1：卡到期了想继续用？**
续费卡：什么都不用做，进站时自动顺延（默许续费）。非续费卡：详情 →「修改」→ 把终止日期改到未来（≥ 今天），卡立即恢复生效。

**Q2：不想再被某张卡吵了？**
三个选择：单次安静 → 本周期静默；永久安静 → 永久静默；彻底不要 → 删除（不可逆）。卡已到期会自动沉底，默认不显示。

**Q3：次数用完了怎么办？**
- 续费 + 固定刷新次数：不用管，下个扣款日自动重置。
- 续费 + 无限：不自动重置。出路：详情直接改剩余 / 批量导入真实次数校准 / 把刷新模式改成固定次数。
- 非续费次卡：改回数字即恢复（沉底自动取消），或等下一次导入覆盖。

**Q4：删除续费中的卡，平台还会扣款吗？**
会。删除只清除本地记录——**先去对应平台 App 取消订阅，再删本地记录**（删除弹窗有强化警告）。

**Q5：为什么清单里看不到我的过期卡？**
默认被「展示已过期的卡片」开关收起。打开开关即可看到（灰色沉底）。

**Q6：为什么自动续费卡的"终止日期"改不了？**
续费卡的终止日期恒等于扣款日，由系统维护。想手动控制日期：先在续费区块关闭自动续费（终止日期会停在最后一次扣款日），再修改，之后可按需重开。

**Q7：导入后为什么没有立刻弹提醒？**
导入不触发提醒（提交时你已在预览里核对过）。提醒在**下次进站**时按新数据统一计算。

**Q8：同一天既是到期日又是扣款日，为什么只显示一个倒计时？**
续费卡的 DDL ≡ 扣款日，两件事是同一天；扣款窗口（7 天）比到期窗口（15 天）晚进入，系统在扣款窗口内自动切换为"天后扣款"口径，环色变红。

**Q9：两台设备看到的不一样？**
后写覆盖先写 + 进站自动收敛。稍等片刻或刷新即可一致。

**Q10：日历里某张卡不显示？**
日历筛选是"选中集"且最多 5 张。点「卡片筛选 N/M」勾选它；卡数 >5 时新卡默认不选中。
