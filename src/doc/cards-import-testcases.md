## F. 提交门禁与端到端（补充覆盖项，不计入上表编号）

- **canSubmit 门禁**：存在任一解析/分类错误 → 按钮禁用；`validCount = 0` → 禁用；快照加载失败（store.status ≠ ok）→ 禁用。
- **空输入**：空文本 / 纯空行 → 不渲染预览、不可提交。
- **提交成功**：单次 RPC 转发；`today` 取客户端本地日期；成功后清空文本框并显示「新增 N / 更新 N / 跳过 N」。
- **提交失败**：RPC 400 行级错误 → 整批回滚（SQL 事务），页面显示错误 message。
- **CF 层剥离**：显式 `null` 值键在转发前剥离（视同缺失）；白名单外键不入载荷。
