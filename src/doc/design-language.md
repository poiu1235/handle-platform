# Handle 设计语言规范（认证页 + 管理端）

> 覆盖范围：`src/auth.css`（登录/注册/激活/重置密码）与
> `src/pages/board.css`（管理端首页 + 余额批量导入）。
> 结构参照 `src/pages/AuthShell.jsx`、`src/pages/Hello.jsx`、`src/pages/BalanceImport.jsx`。
> 用途：新增页面、组件、弹窗时直接套用本规范，保证视觉一致。

# 第一部分 · 共享设计基础（两套页面通用）

两套页面共用同一套 token 与基础词汇。token 在认证页定义于 `.shell`，在管理端定义于
`.bd-board / .bd-import`，**名称与取值完全相同**。

## 1.1 色彩 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--au-navy` | `#010f1c` | 深蓝渐变的深端（hero/头部背景） |
| `--au-navy-2` | `#04263f` | 深蓝渐变的亮端；也作"重动作"底色 |
| `--au-brand` | `#5BBBEE` | 主品牌蓝：主按钮、链接、选中态、focus 描边 |
| `--au-brand-hover` | `#3FA9E0` | 品牌蓝 hover |
| `--au-brand-soft` | `#E3F3FC` | 品牌浅蓝底（信息提示条、选中排序） |
| `--au-brand-text` | `#1B74A8` | 浅蓝底上的深蓝文字 |
| `--au-text` | `#1A1A1A` | 主文字 |
| `--au-text-2` | `#646464` | 次级文字 |
| `--au-text-3` | `#939393` | 弱文字：placeholder、hint、禁用 |
| `--au-bg` | `#F0F2F5` | 页面底色 |
| `--au-card` | `#FFFFFF` | 卡片/输入框底色 |
| `--au-border` | `#E0E0E0` | 常规描边（唯一中性描边色） |
| `--au-danger` | `#EF4444` | 错误文字/危险动作 |
| `--au-danger-soft` | `#FEE2E2` | 错误浅底 |
| focus 光环 | `rgba(91,187,238,0.25)` 3px | 输入聚焦外发光 |
| 品牌投影 | `rgba(91,187,238,0.45~0.5)` | 品牌蓝元素 hover 光晕 |

深蓝渐变公式：`linear-gradient(160deg, #04263F 0%, #010F1C 72%)`。
**深蓝渐变只允许出现在品牌区/头部**，内容区背景只能是 `#F0F2F5` 或白色。

## 1.2 字体

```css
font-family: 'PT Sans', 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

- 西文/数字 PT Sans（400/700）；中文沿用 Noto Sans SC webfont（400/700），苹方/雅黑仅作加载失败兜底。全站统一，组件不得另指定。
- 加载白名单：全站只加载这两族字体，且**只在 index.html 的 Google Fonts 链接里加载一次**（CSS 内禁止 `@import` 字体）——历史上出现过 Noto Sans SC 被双份加载且字重集合不一致的问题，此规则即为杜绝复发。
- 字重只有 **400 / 700** 两档；强调一律 700，禁用态可降回 400。
- 英文小标签统一「全大写 + 1.5px 字距」。
- 数字展示场景（金额、表格数值）用 `font-variant-numeric: tabular-nums`。

## 1.3 形状与描边

- 圆角阶梯：**8 / 10 / 12 / 16 / 24 / 999(胶囊)**。小控件 8–12，容器 16，胶囊按钮/分段控件 999。
- 唯一常规描边 **1px `#E0E0E0`**（输入框、白色容器、ghost 按钮）；强调靠颜色不靠描边。
- focus 公式：`border-color: 主色` + `box-shadow: 0 0 0 3px 主色@25%`。

## 1.4 动效

- 基础过渡 `0.15s ease`；入场/展开 `0.2–0.36s`，曲线 `cubic-bezier(0.22,1,0.36,1)`（利落）
  或 `cubic-bezier(0.34,1.56,0.64,1)`（弹簧）。只过渡颜色/阴影/透明度。
- **新交互动效一律采用布局属性（left/width）或纯色过渡，不用 transform 常驻**：
  transform 会把元素常驻合成层，Windows Chrome 会把旁边文字切到灰度抗锯齿导致发糊。
  仅入场/飞出等瞬态动画可用 transform（结束后归零）。
- 移动端优先书写，桌面端只做增强；必须包含 `prefers-reduced-motion` 全局兜底。
- z-index 层级表：普通内容 < 展开卡片(1000) < FAB(1010) < 弹窗遮罩(1020)。
  任何"浮层"必须高于展开卡片，否则会被盖住。

# 第二部分 · 认证页设计规范（auth.css）

## 2.1 风格定位

- **移动端优先的 App 式认证页**：顶部深蓝品牌区（hero）+ 底部白色圆角表单面板向上叠进 hero，
  形成类似原生 App 的「头图 + 抽屉面板」结构。
- **扁平化**：组件本身不带渐变、不带重阴影，层次靠「颜色深浅 + 圆角大小 + 克制的投影」表达。
- **单强调色策略**：大面积使用中性色，品牌天蓝只出现在动作和强调点上。
- 深蓝渐变只允许出现在品牌区/头部，不做内容区背景。

## 2.2 色彩体系

共享 token 之外，认证页专用：

| 值 | 用途 |
| --- | --- |
| `rgba(255,255,255,0.45)` | hero 副标题（英文小字） |
| `#FFFFFF` | hero 主标题与 logo 白色部分 |
| logo 水印 `opacity: 0.12` | hero 右下角装饰，溢出裁切；定位**跟随内容列（420px 卡）右缘**：`right: max(-34px, calc((100% - 420px) / 2 - 34px))`，宽屏不贴屏幕右缘 |
| `#F5F7F8` | 禁用输入框底色 |

## 2.3 字号阶梯（认证页）

10px（hero 英文副标题，uppercase+1.5px 字距）／12px（eyebrow、field-hint）／
13px（表单 label、notice、toggle-row——认证页标准正文）／14px（桌面输入框）／
15px（主按钮）／16px（移动端输入框，必须 ≥16px 防 iOS 缩放）／
20px（页面 H1、验证码输入框，验证码另加 700 字重 + 8px 字距）。

品牌字标：hero 产品名不使用文字，统一用 SVG 字标
`src/assets/font_daoliti.svg`（白色填充，viewBox 已裁紧为 410×41.6），
以 `<img class="brand-word">` 嵌入，`height: 17px`、宽度按比例自适应，
`alt="Handle 数据管理端"` 保留可访问性。

## 2.4 排版与布局

```
.shell（100dvh 纵向 flex）
├── header.shell-header   深蓝渐变 hero：logo + 产品名 + 英文副标题 + 右下角水印
└── main.shell-main → div.ledger-card：eyebrow + H1 + notice + 表单 + 胶囊按钮
```

- 移动端：hero 竖排居中 `padding: 24px 20px 38px`，logo 54×54；
  面板贴边、`margin-top: -20px` 上叠、只圆顶部两角（24px）、
  向上投影 `0 -6px 24px rgba(1,15,28,0.14)`、内边距 22/22/48。
- 桌面 ≥720px：hero 压扁横排（logo 40×40）；面板居中 max-width 420px、
  四角 16px、1px 描边 + `0 2px 8px rgba(0,0,0,0.1)`、内边距 34/32/28。
- 卡片内节奏：eyebrow 4px → H1 18px → notice 14px → 字段 14px → toggle-row 14px → 按钮 4px。

## 2.5 组件规范

- **输入框**：高 48px；圆角 10px（移动）/8px（桌面）；1px `#E0E0E0`；白底无阴影；
  字号 16px（移动）/14px（桌面）；带图标时左留白 44px；focus 蓝描边 + 3px 光环；
  disabled 灰底灰字。
- **字段图标**：18×18 绝对定位 left 14px；线性 SVG（stroke 1.8、圆头、单色 `#939393`），
  画在独立 `.field-icon` 元素上（绕开自动填充对 input 背景的强占）。
- **提示条 notice**：13px、padding 11×14、圆角 10、**无左侧色条**；
  信息态 `#E3F3FC`+`#1B74A8`，错误态 `#FEE2E2`+`#EF4444`。一切反馈都用它。
- **主按钮**：全宽胶囊 48px（圆角=高一半）、品牌蓝底白字 15px/700、无边框；
  hover `#3FA9E0` + 品牌投影；disabled opacity 0.5；focus-visible 2px outline。
- **辅助行 toggle-row**：居中 13px `#646464`；链接品牌蓝 700，hover 加深+下划线；
  disabled `#939393`/400。
- **验证码输入**：20px/700/字距 8px，shield 图标。

## 2.6 未来认证页设计守则

1. 只复用 token；需要新颜色先扩 token。2. 字号从阶梯取，强调只加 700。
3. 表单页套同一骨架。4. 输入框一律 48px + 1px 灰描边 + focus 光环，移动端字号 ≥16px。
5. 图标统一线性风格。6. 反馈一律 notice。7. 一页一个主按钮，次要动作文字链接。
8. 深蓝渐变只用于头部。9. 圆角阴影按阶梯取值，过渡 0.15s。
10. 品牌装饰用英文 uppercase 小字，功能文案用中文。
11. 选择器限定在页面根容器之下。12. 移动端优先，720px 起做桌面增强。

# 第三部分 · 管理端设计规范（board.css，`/app` 与 `/app/balance-import`）

## 3.1 风格定位

- **信息密度更高的工具页**：深蓝 hero 头部（与认证页同源）+ 浅灰内容区 +
  白色「卡包层叠」卡片列表；品牌蓝依旧是唯一强调色。
- **内容列限宽**：全站内容收在 `--bd-col: 560px` 一列，居中；
  侧边距 `--bd-gutter: max(16px, (100% - 560px) / 2)`——移动端留 16px 呼吸边，
  宽屏自动居中（与认证页卡片居中同一逻辑）。
- 彩色是管理端的表达语言：每条记录一个专属色（id 哈希取色，永不变色），
  但底色、容器、控件全部遵守共享 token，色彩只出现在「内容」上。

## 3.2 色彩

共享 token 之外，管理端专用：

| Token/值 | 用途 |
| --- | --- |
| `--bd-zero-card: #CDD3D9` | 0 余额卡片底（比页面底 `#F0F2F5` 明显深一档） |
| `#6B727A` | 0 余额卡片文字（名称/金额/单位） |
| `--bd-col / --bd-gutter` | 内容列限宽与侧边距 |
| 记录色板（JSX `PALETTES`） | 余额=16 色暖橙黄盘；会籍=青蓝盘；优惠券=粉绿盘；按 id 哈希分配 |
| 动作三色 | 修改=`--au-brand`、删除=`--au-danger`、清零/提交态=`--au-navy-2` |

**色彩语义**：蓝=常规动作与选中；红=破坏性动作；深蓝=不可逆的「重」动作（清零）；
灰=零值/不可用；彩色卡片=记录身份。

## 3.3 字体与字号阶梯

字族同共享基础。管理端阶梯：

| 字号 | 使用场景 |
| --- | --- |
| 11px | 分类标签计数、导入表格表头（uppercase + 1px 字距） |
| 12px | eyebrow、排序按钮、卡片日期（meta）、金额单位、导入错误行 |
| 13px | 标签分类名、开关文字、notice、字段 label、滑动操作按钮、FAB 菜单项、text-btn、表头列、modal hint |
| 14px | 主按钮/ghost、深滑提交态「清零」、textarea 输入、导入说明文案 |
| 15px | 卡片折叠态名称、全宽提交按钮、退出登录（text-btn） |
| 16px | 卡片展开态名称、弹窗输入框（≥16px 防 iOS 缩放） |
| 18px | 弹窗标题 |
| 20px | 卡片金额（页面 H1 已改用字标，见 3.4） |
| 28px | FAB 的 + 字形 |

规则同认证页：400/700 两档；金额与表格数值 `tabular-nums`；强调只加 700。

## 3.4 排版与布局

**管理端首页骨架**（`height: 100dvh` 列，列表内部滚动）：

```
.bd-board
├── header（深蓝渐变横带 + logo 水印）：eyebrow + H1 + 退出登录 + 登录态胶囊
├── nav 分类标签（白色分段控件）
├── 排序行（幽灵胶囊 ×3）
├── 0 余额开关行（仅余额标签）
├── .bd-list（flex:1 内部滚动，底部预留 120px 给 FAB）
├── FAB（absolute 底部居中）
└── 弹窗 ×2（fixed）
```

- 头部内容与下方各区块统一受 `--bd-gutter` 约束，左缘对齐；
  登录态是「圆点 + 邮箱」的半透明胶囊，**与内容列左缘对齐**（不居中）。
  头部水印（logo 12% 透明度）**跟随内容列右缘**：`right: max(-30px, calc((100% - var(--bd-col)) / 2 - 30px))`——移动端贴屏幕边，宽屏贴列右缘，切勿写死贴屏幕右缘。
  品牌字标同认证页（`font_daoliti.svg`，白字）：管理端页面 H1 以 `<img class="bd-title-word">`（高 22px）替代文字标题，`alt="Handle 数据管理端"` 保留语义。
- **卡包层叠**：折叠卡片 `margin-top: 8px`，相邻折叠卡 `-16px` 叠压，
  前卡盖住后卡下边缘、露出一点顶边（行 z-index = 总数-序号）；展开行上下留 10px、跳到 z 1000。
- **展开行为**：点卡片展开（同时只一张），跳最上层、多一行日期、
  `scrollIntoView({ block: 'center' })` 平滑滚到屏幕中央；再点收起。
- **导入页骨架**：`min-height: 100dvh` 列，深蓝头部（说明文案也在 hero 内，
  `rgba(255,255,255,0.72)`）+ 内容列（textarea → 解析预览 → 全宽提交按钮 → 结果 notice）。

## 3.5 组件规范

### 分类标签（分段控件）
白色胶囊容器（padding 4px、1px 描边、圆角 999），内含三个等宽分段；
选中段品牌蓝底白字 + `0 2px 8px rgba(91,187,238,0.4)` 投影 + 弹跳入场；
计数徽章：未选中灰底灰字、选中白 25% 透明底白字。

### 排序按钮
幽灵胶囊（白底、1px 描边、12px）；选中态品牌浅蓝底 + 品牌蓝描边 + 深蓝文字，
文字后跟 ↓/↑ 方向符。0 余额记录永远沉底，不参与主排序。

### iOS 开关（0 余额）
轨道 42×24 圆角 999（灰 `#C8CFD6` → 选中品牌蓝），滑块 20×20 白圆带小投影。
**动画用 `left: 2px → 20px`（弹簧曲线）而不是 transform**——原因见 1.4（避免文字灰度 AA 发糊）。
按压形变（对齐旧版 tgl-ios）：按住时轨道内陷（inset 阴影）+ 滑块 `width: 17px` 压扁；
开启态按住只压扁不位移。label hover 时文字加深；keyboard focus 有品牌光环。

### 余额卡片（核心组件）
- 结构：左「◆ 名称（+展开态日期行）」右「金额 + 单位」；圆角 16。
- 折叠态：padding 16/18，投影 `0 3px 8px rgba(1,15,28,0.10)`，只显示名称+金额。
- 展开态：padding 18/20，投影加深 `0 10px 26px rgba(1,15,28,0.16)`，名称升到 16px，
  多一行「YYYY年MM月DD日更新」（12px、60% 透明度，**nowrap+ellipsis**，防止挤压换行撑高）。
- 省略规则：名称与日期 nowrap+ellipsis；金额列 `flex: none` 不收缩。
- **金额淡出**：卡片剩余宽度 <150px 开始淡出、<90px 完全消失
  （透明度 = (剩余宽度-90)/60），防止右滑深滑时金额溢出画到卡片外。
- 零余额：灰底 `#CDD3D9` + 深灰文字，沉底。
- 接缝联动：滑出操作面板时，卡片接缝一侧改为直角
  （`.bd-card-seam-right/left`），整行读作一个连续圆角整体。
- 入场：交错上浮（每张延迟 index×40ms，0.5s ease-out）。

### 滑动操作
- 仅余额标签、仅展开卡响应；Pointer Events 统一触屏/鼠标。
- 左滑 → 右侧「修改（品牌蓝）」「删除（红）」，面板宽封顶 132px；
  松手超 40px 或快速左甩即吸附。右滑 → 左侧「清零（深蓝）」，
  基础展开 92px；拖过卡片一半或快速右甩 = **直接提交**（面板变填充态大「清零」，
  卡片向右飞出 220ms 后调用接口，无二次确认）。
- 面板吸附过渡 `width 0.24s ease-out`；拖动/惯性期间由 JS 逐帧接管（transition: none）。

### FAB 与菜单
56px 品牌蓝圆钮（品牌色投影）；点开旋转 135° 变深蓝「×」，
弹白色胶囊菜单【批量增加】【增加一条】（错峰弹入，hover 上浮），
遮罩**全透明**（只做点击关闭的热区）。位置底部居中，z-index 1010。

### 弹窗
遮罩 `rgba(1,15,28,0.42)` + 3px 模糊，z-index 1020（必须高于展开卡）；
卡片 min(400px,100%)、圆角 16、spring 缩放入场；标题 18/700；
提示块=notice 同款（信息蓝/危险红）；输入框 46px、圆角 10、focus 光环、自动聚焦；
按钮右对齐：胶囊「保存（品牌蓝）/取消（ghost）/确定删除（红）」，
提交中显示「保存中…」且双按钮禁用。

### 导入页组件
- textarea：min-height 240、圆角 12、等宽示例占位文案、focus 光环、可纵向拉伸。
- 解析预览：白卡圆角 12 + 上滑入场；标题行含条数与重名提示；
  错误块浅红底圆角 8（每行「第 N 行：原因 —原文」）；表格发丝线、表头 uppercase、数值右对齐。
- 提交：全宽胶囊 48px；≥1 条有效且零错误才可点；提交中「提交中…」禁用。

## 3.6 圆角 / 描边 / 阴影体系

| 圆角 | 用在哪 |
| --- | --- |
| 10px | 弹窗输入框、notice |
| 12px | textarea、解析预览卡 |
| 16px | 卡片、弹窗卡（错误块 8px 例外） |
| 999 | 分段控件、排序/按钮/菜单/FAB 全胶囊 |

- 描边：1px `#E0E0E0`（分段控件容器、排序按钮、textarea、预览卡、ghost 按钮、菜单胶囊）；
  hero、卡片、操作按钮无边框——彩色卡片靠色块本身，白色区域靠投影分层。
- 阴影表：折叠卡 `0 3px 8px rgba(1,15,28,0.10)`；展开卡 `0 10px 26px rgba(1,15,28,0.16)`；
  FAB `0 8px 20px rgba(63,169,224,0.45)`；菜单胶囊 `0 4px 14px rgba(1,15,28,0.14)`；
  弹窗卡 `0 24px 60px rgba(1,15,28,0.28)`；输入框永远无阴影。

## 3.8 管理端设计守则（未来执行）

1. 颜色只复用 token；记录专属色只允许出现在卡片底/书脊等「内容载体」上。
2. 内容列永远 560px 限宽居中（gutter 公式照抄），新区块左缘与列对齐。
3. 列表类页面套骨架：hero 头部 + 分段/工具行 + 内部滚动列表 + FAB + 弹窗。
4. 卡片文字必须自带省略规则；固定宽度列（金额）在空间不足时按淡出公式隐藏。
5. 滑动操作沿用三色语义与全部阈值常量（66/40/0.5/132/92/50%/220ms）。
6. 浮层 z-index：展开卡 1000 < FAB 1010 < 弹窗 1020，新增浮层按此插入。
7. 反馈一律 notice；不可逆动作用红色 + 确认弹窗，「重」动作（清零）用深蓝。
8. 深蓝渐变只用于头部；开关等微交互动画用布局属性，不用常驻 transform。
9. 圆角/阴影按 3.6 阶梯取值；过渡时长 0.15–0.36s，曲线二选一（ease-out/弹簧）。
10. 文案分工：眉题/装饰英文 uppercase，功能文案中文；金额 tabular-nums。
