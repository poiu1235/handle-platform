## GUI 验证步骤（人工核对项）

1. 登录 → 会员管理页 → 右上「批量增加会员卡」（或 FAB「批量增加」）进入 `/app/cards-import`。
2. 整段粘贴（含表头）→ 预览出现「**新增 20 条**」分组，错误区不出现，
   按钮可用且文案为「**提交（新增 20 · 更新 0）**」。
3. 逐行核对第 1 列表格的标注（默认 tag /「新增过期记录」黄标 /「次数能力开启」），
   续费 8 行的「续费」列应显示 `开 · 每X · 日期 扣款` 且日期 = 各自终止日期。
4. 点击提交 → 成功提示「**已提交：新增 20 / 更新 0**」，文本框清空。
5. **幂等回贴**：再次粘贴同一份 → 预览转「**更新 19 条 · 跳过 1 条**」
   （第 5 行库内已过期 → 跳过），每张卡显示「与库内当前状态一致，无字段变化」；
   提交文案「提交（新增 0 · 更新 19）」；成功提示「已提交：新增 0 / 更新 19 / 跳过 1」。
   （探针 C 组已按同口径实测断言。）
6. 若库内已有同名卡（上次运行残留），对应行会转入「更新」组显示 旧 → 新 对照，属正常不算错误；
   建议先清库或换卡名再跑"全新增"基线。
